// about

froots are what grow when Bitroot plants ideas.

We kept building capabilities inside individual projects, then re-cloning repos and passing around keys every time a teammate or a new agent needed them. froots ends that: every useful thing we make becomes a hosted MCP server — one endpoint, keys server-side, access by revocable token.

Point Claude Desktop, Claude Code, or bit-cli at a froots URL and the tools just appear. No clone, no install, no shared secrets. The froots of our labor — ripe for any agent to pick.
